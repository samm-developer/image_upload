# Presigned URL image upload

A React frontend uploads image bytes directly to Amazon S3 using a short-lived presigned URL generated by a Node.js AWS Lambda handler. PostgreSQL stores upload metadata and status.

## Run locally

### Backend

```bash
cd backend
cp .env.example .env
# Set S3_BUCKET_NAME and ensure AWS credentials are available
npm install
npm run db:init
npm run dev
```

### Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Open `http://localhost:5173`. The PostgreSQL URL is accepted exactly as provided; the backend converts the `postgresql+psycopg://` scheme to the Node-compatible `postgresql://` scheme.

## AWS notes

Deploy `backend/src/handler.js` with `backend/template.yaml` or connect it to API Gateway. The Lambda execution role needs `s3:PutObject` on the upload bucket and network access to PostgreSQL. Set S3 bucket CORS to allow `PUT` from the frontend origin.
